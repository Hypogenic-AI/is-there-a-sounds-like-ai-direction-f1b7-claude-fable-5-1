# Feature-Level Insights into Artificial Text Detection with Sparse Autoencoders (arXiv 2503.03601v1, 5 Mar 2025)

Kuznetsov, Kushnareva, Druzhinina, Razzhigaev, Voznyuk, Piontkovskaya, Burnaev, Barannikov.
22 pages (short paper: main text p1-5, appendices A-H p8-22). All chunks read.
Page refs are PDF pages. "[unsure]" marks things not stated or read off a figure.

## Relevance in one line
Finds Gemma-2-2b SAE features (layer 16) that detect AI text, and DOES steer generation with single
SAE features, but evaluates steered output only qualitatively (GPT-4o description). It never measures
whether steering changes a detector's score.

## Research question (Sec 1, p1)
Which SAE features of Gemma-2-2b's residual stream are useful for artificial text detection (ATD),
what do they mean, and how do they vary across domains and generator models?

## Method (Sec 3, p2)
- Model: Gemma-2-2B with pre-trained Gemma Scope residual-stream SAEs (Lieberum et al. 2024).
  One SAE per EVEN layer. SAE width / L0 variant NOT stated; feature indices go up to at least 16302,
  consistent with a 16k dictionary [unsure, inferred].
- Text-level feature vector: SUM of SAE feature activations over all tokens, f = sum_i f^(l)(x_i^(l)).
  No length normalisation (so features scale with text length).
- Classifiers: XGBoost on the full per-layer SAE feature vector; compared with XGBoost on mean-pooled
  raw layer activations ("Embeddings"). Also single-feature THRESHOLD classifiers per domain / model.
- Feature selection for interpretation: layers 8-20; top-20 XGBoost-importance features plus every
  feature that is the best threshold detector for some domain or model.
- Interpretation: (a) manual reading of max-activating texts, (b) steering + GPT-4o description.

## Datasets and sizes
- COLING 2025 GenAI Content Detection Task 1 (Wang et al. 2025). Splits used: Train (training only),
  Dev, Devtest, Test. Sizes are NOT given in this paper. Generators (App B, p8): LLaMA 7-65B,
  LLaMA-3 8B/70B, GLM-130B, Bloom/Bloomz 7B, Cohere, davinci-001..003, gpt-3.5-turbo, GPT-4, GPT-4o,
  T5/T0-based (flan), Gemma 7B, Gemma-2 9B, GPT-J 6B, GPT-NeoX 20B, Mixtral 8x7B, OPT 125M-30B, Dolly.
  Domains in Fig 4: arxiv, cmv, eli5, finance, hswag, medicine, open_qa, outfox, peerread, reddit,
  reddit_eli5, roct, sci_gen, squad, tldr, wiki_csai, wikihow, wikipedia, wp, xsum, yelp.
- RAID (Dugan et al. 2024) for robustness analysis: only ChatGPT, GPT-4 and human used; 100
  continuations per (domain, model, decoding, penalty, attack) combination (App C, p9).

## Baselines
XGBoost on mean-pooled activations; the "MTL" SOTA system (Gritsai et al. 2025, Advacheck) on COLING.

## Metrics and headline numbers
Metric: Macro-F1. Numbers below are read off figures [approximate].
- Fig 2 (p3): SAE features beat raw activations at every layer on Train/Dev (~0.92-0.96 vs ~0.86-0.91),
  Devtest (~0.83-0.92 vs ~0.74-0.84) and Test. On Test, SAE at layer 16 slightly exceeds the MTL
  line (~0.83-0.84). Layer 16 = most expressive / best generalisation; all later analysis uses L16.
- Single-feature threshold classifiers, layer 16 (Fig 3, 4, 16):
  - "General"/"universal" features 3608 and 4645 work across most generators; they fall below chance
    on older models (flan-T5, T0); OPT family is the "most universal".
  - By domain (Fig 4; cols 3608 / 4645 / 6587): finance .97/.89/.99, medicine .98/.92/.99,
    reddit_eli5 .98/.93/.99, wiki_csai .97/.76/.99, open_qa .94/.82/.96, but arxiv .62/.73/.79,
    xsum .50/.51/.45, yelp .59/.64/.51, outfox .49/.54/.52.
  - By model (Fig 16; cols 3608 / 4645 / 14161 / 8264): gpt-35 .97/.88/.63/.98, gpt4 .91/.75/.74/.99,
    gpt4o .78/.91/.60/1.00, dolly-v2-12b .92/.87/.86/.91, gemma2-9b-it .71/.80/.56/.95,
    flan_t5_xl .47/.37/.57/.33, t0_11b .43/.41/.46/.43.

## Gemma-2-2b layer-16 SAE features and interpretations (Sec 5 p4; App F p12-14; Tables 3-6 p17-19)
Each has three readings: manual (max-activating text) / GPT-4o auto / steering effect.
General (robust) features:
- 3608: manual = ill-posed characters / words that normally occur in scientific context (numbers,
  brackets, "n", "neighbourhood"); steering = sentence complexity: negative -> short choppy sentences,
  >= +2.0 -> overly complex multi-clause sentences. Summary label: "excessive complexity".
  Neuronpedia label "tokens associated with mathematical expressions" (authors say too narrow).
- 4645: manual = long "lively" stories of common phrases, hard-to-follow objective, factual
  contradictions; steering = assertion strength: negative -> hedging ("Some scientists believe..."),
  positive -> assertive definitive claims ("Scientists have proven..."). Label: "assertive claims".
  Neuronpedia label "keywords on diabetes".
- 6587: manual = numbered lists / structured step-wise text, intro words; steering = directness vs
  buildup: negative -> concise / abrupt, positive -> long-winded introductions. "wordy introductions".
- 8264 (GPT-family): manual = long "gpt-style" instructions, verbose and obvious; activates on long
  common words typical of GPT style; steering = redundancy: negative -> underdeveloped explanations,
  positive -> excessive repetition, sentences looping around one idea. Near-perfect F1 on GPT-3.5+;
  older models lack it.
- 14161: "formality" (named in Sec 5 only; no table entry or steering detail given).
GPT-specific:
- 8689: manual = long "gpt-style" instructions; HIGHLY SENSITIVE to the "...." punctuation anomaly;
  steering = lexical diversity: negative -> word repetition, positive -> excessive synonym
  substitution. Flagged as length / anomaly-sensitive (Table 1).
Domain-specific:
- 12390 (arxiv, F1 1.00): linking words in dependent syntactic structures; steering = syntactic
  complexity.
- 1416 (wikihow, .93): scientific text with missing formulas / symbols (parsing errors), abnormal
  punctuation; steering = abstract / philosophical / metaphorical expansion; hallucinations in
  factual prompts, creativity in fiction.
- 6513 (finance, .83): manual = highly informal, opinionated speech ("I mean", "like"); steering =
  factual density vs elaboration (positive -> unnecessary background; adds positive sentiment in
  opinion contexts). Main text labels it "excessive details".
- 14953 (medicine, .96): manual = second-person recommendations ("You should ..."); GPT-4o says
  formality / academic tone (negative casual, positive formal); actual +4.0 outputs turn every
  response into "contact your local office"-style advice (Table 7, p20). Main text: "improper tone".
- 4560 (reddit .82, reddit_eli5 .95): informal internet discussion, short first-person sentences,
  "Yeah", "Ah", datetime labels; steering = speculative causal links.
- 4773 (wikipedia, .82): words repeated in many morphological / synonym forms, corrupted words;
  steering = hallucinated details. Also "enhances writing sophistication" (App H).
- Other L16 indices appearing only in figures, uninterpreted: 6953; model-specific 11572, 13889,
  9966, 6689, 3644, 9525; 14919 (Bloom family; length / anomaly-sensitive).
- Hand-identified markdown-paragraph features: 1033 and 15152 (L16), unstable across domains (p12).

## STEERING experiments (Sec 3 p2; App G, H p14; Tables 3-7; Fig 17 p22)
- What: one SAE decoder direction d_i (column of W_dec) added to the hidden state:
  x' = x + lambda * A_max * d_i, where A_max = feature's max activation over a reference dataset.
- Coefficients lambda in {-4.0, -3.0, -2.5, -2.0, -1.5, -1.0, -0.5, 0.5, 1.0, 1.5, 2.0, 2.5, 3.0, 4.0}.
  Applied to ALL tokens ("In steering, we adjust a feature's value across all tokens, while in real
  texts, it activates on only a few", p12).
- Steered model / layer / decoding settings are NOT stated explicitly; presumably Gemma-2-2b at the
  feature's own layer (16) [unsure]. The reference dataset for A_max is not named.
- Prompts shown (Table 7): P1 "The first person to walk on the Moon was...", P2 "The Atlantic Ocean
  separates the continents of...", P3 a short first-person Reddit-style passage. Continuation task,
  i.e. raw text completion, not chat format.
- Evaluation: GPT-4o is given, per feature, sequences of 50 generations (original + progressively
  shifted versions) and asked to describe what changes (prompt in Fig 17). Output is a qualitative
  table (weakening <= -2.0 / neutral 0.5-1.5 / strong >= +2.0).
- NOT done: no detector (XGBoost, threshold feature, or external) is run on steered text; no
  quantitative effect size; no fluency / perplexity control; no random-direction control; no
  multi-feature or "AI-ness" composite steering. Steering is used for INTERPRETATION only.
- Authors' caveat (App H): GPT-4o descriptions miss some effects; effects are context-dependent
  (6513, 1416, 14953 behave differently on factual vs opinion vs fiction prompts).

## Confound controls (App B, D; Tables 1-2, p8-16)
- Dataset artefacts documented: spaces before commas and commas after line breaks are common in
  HUMAN COLING texts (preprocessing artefact); "...." most frequent in GPT-NeoX; GPT-4o uses "\n\n"
  in almost every text, Gemma / LLaMA-3 in more than half; T5 / T0 texts are much shorter (Fig 11).
- Length (App D.1): on human texts only, per domain (> 1000 samples), top-10% longest vs shortest;
  top-10 features by mean difference, intersected across domains. Length-sensitive features:
  L16: 1033, 16028; L18: 7373; L20: 8684.
- Syntactic anomalies (Table 1): space-before-comma: L18 2199, L20 6631 (none at L16);
  "....": L16 2889, 8689, 14919; L18 3851, 12685, 16302; L20 8573, 11612, 12748;
  "\n,": L16 14919, 16028; L18 12685; L20 8573, 12267. No stable feature for "##" or "\n\n".
- Main text (p4) says 8689 (GPT-3.5+) and 14919 (Bloom) are "very sensitive to sentence length";
  Table 1 actually lists them under the "...." anomaly, not the Length column [inconsistent].
- Attacks on RAID (Table 2, p16), computed within the top-10% XGBoost-important features. L16:
  article deletion 3518, 13998; homoglyph 9266; whitespace 9266, 5627, 10229, 750; zero-width space
  9266, 10262; upper/lower 13998; synonym 4052, 9100, 13998. L20: 11612 (article deletion,
  upper/lower with 3302, synonym); homoglyph 15523, 9589, 743; whitespace 12602, 11363, 15415, 3879;
  zero-width 6793, 9589. L18 row lists 7905, 2006, 8408, 4859, 3037, 281, 1970, 15780, 12530, 1642,
  13017, 10815 [column alignment unsure in the PDF]. No stable feature for number-shuffle, paragraph
  insertion, alternative spelling, misspelling or paraphrase.
- Claim: attack / shallow-property features overlap minimally with the best ATD features (only 8689
  and 14919 overlap).
- Formality: not controlled; it is one of the identified AI-text features (14161; 14953 via steering).
- Domain: handled by per-domain threshold analysis, not by matched design. Features are strongly
  domain-dependent (strong in finance / medicine / wiki_csai, near chance on xsum / yelp / outfox).
- Sum pooling means every feature is confounded with length to some degree [my observation; the
  paper only reports the top length-sensitive features].

## Key qualitative conclusions (Sec 5-6, p4)
- Modern LLMs have a detectable default style: long-winded introductions, excessive synonym
  substitution, repetition, over-complexity, assertiveness, formality.
- Detection is easy with a default prompt but hard when prompt style changes (essays / Outfox,
  reviews / Yelp): "general overcomplexity features may not be effective when models are instructed
  to avoid such traits". arXiv is less distinguishable (GPT mimics scientific writing).

## Limitations stated (Sec 7, p4-5)
Unknown behaviour on future generators; covers only a subset of attacks; some features not clearly
interpretable; single SAE family on Gemma-2-2B only.
